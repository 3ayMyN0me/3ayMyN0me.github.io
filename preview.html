2025.05.10 HackTheBox Easy Linux

Sample Box — Easy Linux Foothold to Root

A walkthrough of an easy Linux target: an exposed web app leaks credentials through a local file inclusion bug.

#web#lfi#sudo#privilege-escalation#enumeration
// target recon
platformHackTheBox
operating systemLinux
difficultyEasy
target10.10.11.42
tools usednmap · gobuster · Burp Suite · linpeas

Reconnaissance

I always start with a full TCP port scan, then a targeted service/version scan on the open ports.

# Quick discovery of open ports
nmap -p- --min-rate 5000 -T4 10.10.11.42 -oN scans/all-ports.txt

# Targeted service + script scan
nmap -p 22,80 -sCV 10.10.11.42 -oN scans/services.txt

Two services are exposed: OpenSSH on 22 and an Apache web server on 80. The web server is where I'll focus.

TIP

Never stop at the first scan. A --min-rate sweep is fast but lossy — re-run a full scan in the background while you enumerate.

Foothold

Directory brute-forcing reveals a hidden admin area with an unsanitised page parameter — a classic Local File Inclusion that leaks a reused database password.

ROOT

A wildcard tar pattern in a privileged backup script lets a local user execute an arbitrary command as root — full compromise.

Takeaways

  • LFI is rarely the end goal — it's a credential-discovery primitive.
  • sudo -l is the single highest-value command on any Linux foothold.
  • Wildcard injection in privileged scripts remains shockingly common.
